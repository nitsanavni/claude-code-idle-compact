idle-compact at a glance: the parts, and how they work together

You talk with Claude inside Claude Code, and the conversation keeps growing. idle-compact is a small add-on that notices when you have stepped away, and asks Claude Code to shrink the conversation to a summary before you come back.

Nothing here leaves Claude Code: idle-compact only listens for two events and asks for one thing, a compaction that Claude Code already knows how to do.

How to read this diagram

Each box is one of the parts. Follow the numbered circles in order: each one sits on an arrow in the drawing and has its sentence underneath.

  • You — the person typing
  • The conversation — one session: everything said so far
  • idle-compact — a mod: waits for quiet, then checks the size
  • Compaction — the history is swapped for a short summary
  • Large shaded frame — Claude Code: everything inside it is part of the app or runs inside it.
  • Dashed frame — the plugin system, the part of Claude Code that lets add-ons ("mods") react to what happens.
  • Arrow — one part acting on, or telling something to, another. Two heads: it goes both ways.
  • Numbered circle — a step, in the order things happen. Its color is the part that acts.
  • Bar — how full the conversation's context window is.

The words used here:

  • Claude Code — Anthropic's coding assistant. It runs on your own computer (a local session) or on a remote machine you reach from the web or your phone (a cloud session).
  • Session — one conversation with Claude Code, from start to finish.
  • Context window — everything Claude reads to answer you: the whole conversation so far. It is measured in tokens (a token is roughly three quarters of a word) and it has a size limit.
  • Mod, plugin — an add-on that Claude Code loads. The plugin system tells it about events, such as a reply ending, and lets it ask Claude Code to do things.
  • Compaction — Claude Code's own feature for shrinking a conversation: it writes a summary and continues from that. idle-compact does not do the summarizing; it decides when to ask.
  • Idle — nobody has sent a message for a while. That is when a big conversation is worth compacting: by the time you return, re-reading all of it would be slow and costly.

step  you <-> talk      You and Claude take turns. Every message and reply is added to the conversation, so it keeps growing.
step  talk -> mod       Claude Code tells its mods whenever Claude finishes a reply, and whenever you send a new message.
step  mod -> mod        idle-compact starts a countdown when a reply ends (20 minutes by default). A new message cancels it.
step  mod -> compact    If the countdown runs out and the conversation is big enough, idle-compact asks Claude Code to compact.
step  compact -> talk   Claude Code replaces the conversation with the summary, so your next message starts small and fast.
