How idle-compact decides when to compact

When Claude finishes replying, idle-compact starts a countdown, and your next message cancels it. If the countdown runs out, the conversation is compacted, but only when it is big enough to be worth it.

After any outcome the timer rests until Claude finishes its next reply. The numbers shown are the defaults: 20 minutes and 120,000 tokens are both settings.

How to read this diagram

Each pill is a state the timer can be in; the mod is in exactly one of them at a time. Each arrow is a way to move between states, labelled with what makes it happen.

  • Resting — no countdown running
  • Counting down — 20 minutes by default
  • Size check — is it big enough?
  • Compacted — and you are notified
  • Left alone — too small to matter
  • Dry run — a report, no change
  • Requested — waits for the reply to end
  • Filled dot — where things begin: a session starting, or Claude asking for a compaction.
  • Arrow — a transition, with its trigger written next to it.
  • Dashed arrow — a transition you start on purpose, not by waiting.
  • Loop — the state starts over: the countdown begins again from the top.

The words used here:

  • Compact — Claude Code replaces the conversation so far with a short summary of it, so there is far less to re-read.
  • Big enough — the conversation holds at least 120,000 tokens (a token is a small piece of text, roughly three quarters of a word). Smaller conversations are cheap to re-read, so they are left alone.
  • Notified — a short message on screen, a line in the mod's log, and a notification on your phone or desktop.
  • Dry run — a setting for trying the mod out: it reports what it would have done and changes nothing.
  • Claude asks to compact now — idle-compact gives Claude a tool for this (compact_after_turn). Ask Claude to "compact after this turn" and it skips the wait and the size check.
  • Session — one conversation with Claude Code, on your computer or in the cloud.

Only the main conversation moves the timer. Helper agents that Claude starts in the background neither start nor stop it.
