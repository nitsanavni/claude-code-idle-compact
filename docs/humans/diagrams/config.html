idle-compact · configuration

Four layers, merged one setting at a time

Every setting starts at its default. Your plugin options, a project file and live changes made through Claude can each override it, and the last layer to set a value wins. A layer that leaves a setting alone lets the one above it show through.

An example. Here the project file slows the timer to 15 minutes, then a live change in this session asks for 5 minutes and a dry run.

How to read this diagram

Each row is a place a setting can come from, in order: a row overrides every row above it. Each column is one setting. The shaded band at the bottom is what the mod actually uses.

The color of a row says where a value came from:

  • defaults — built into the mod
  • plugin options — /config or settings.json
  • project file — .claude/idle-compact.json
  • live changes — the config tool, per user
  • Filled pill — the value that wins for this setting: no row below it sets the same setting.
  • Outlined pill — a value this row sets, overridden by a row further down.
  • Faint dot — this row leaves the setting alone, so it falls through to the rows above.
  • Thread — carries the winning value down to the result.

Merging happens per setting, not per row: a project file that sets only idleSeconds changes nothing else.
