idle-compact · why

Compact sooner, while the cache is still warm

Claude Code has its own idle compaction, but it waits for about 54 quiet minutes and a 200k-token context, and in cloud sessions it is off. idle-compact steps in after 20 minutes, once the context holds 120k tokens or more.

Both of idle-compact's thresholds are settings: idleSeconds (1200) and minTokens (120000).

How to read this diagram

The plot asks one question: after how long, and at what size, does an idle conversation get compacted? Left to right is how long nobody has typed; bottom to top is how big the context is.

Each shaded corner is where a compactor acts: both of its thresholds are met, so the region opens up and to the right of its dot.

  • idle-compact — compacts here, in local and cloud sessions
  • Claude Code built-in — idle compaction, off in cloud sessions
  • Dot — the corner itself: its time and token thresholds, written beside it.
  • Dashed and hatched — a compactor that exists but does not run here (in cloud sessions).

A conversation that stays idle drifts right. If it is big enough to sit inside a shaded corner when its time comes, it gets compacted.
