idle-compact · why

Idle compaction for cloud sessions, where Claude Code leaves it off

Claude Code can tidy up a conversation that has sat idle, but only when it runs on your computer: in cloud sessions that feature is switched off. idle-compact was built to bring it to the cloud, and it also steps in sooner.

Both of idle-compact's thresholds are settings you can change: idleSeconds (1200, which is 20 minutes) and minTokens (120000).

How to read this diagram

The table on top is the reason idle-compact exists. Each row is a setup, each column is where Claude Code runs, and each cell answers: does a conversation that has sat idle get compacted?

  • Yes — idle conversations are compacted here, once they are idle long enough and big enough.
  • No — nothing compacts an idle conversation here. This is the gap idle-compact fills.

The plot asks: after how long, and at what size, does an idle conversation get compacted? Left to right is how long nobody has typed; bottom to top is how big the conversation is, counted in tokens.

Each shaded corner is where a compactor acts: both of its thresholds are met, so the region opens up and to the right of its dot.

  • With idle-compact — compacts here, on your computer and in the cloud
  • Claude Code alone — compacts here on your computer only, never in the cloud
  • Dot — the corner itself: its time and token thresholds, written beside it.
  • Dashed and hatched — Claude Code's own idle compaction: it exists, but only on your computer, not in the cloud.

A conversation that stays idle drifts right. If it is big enough to sit inside a shaded corner when its time comes, it gets compacted.

The words used here:

  • Compact — Claude Code replaces the conversation so far with a short summary of it. The next message then has far less to re-read, which makes it faster and cheaper.
  • Idle — nobody has sent a message for a while. While you work, Claude Code keeps the conversation cached; after a long pause the cache expires and the whole conversation must be read again.
  • Cloud session — Claude Code running on a remote machine (for example from the web or your phone) instead of on your own computer.
  • Tokens — the units a conversation is measured in; a token is roughly three quarters of a word. "120k" is 120,000 tokens.
