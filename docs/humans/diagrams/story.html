idle-compact · the story

Use Claude Code in the cloud without paying to re-read a big conversation

You work with Claude in a cloud session and want to spend tokens sensibly. The conversation grows large, you step away and forget it, and idle-compact compacts it while you are gone, so coming back costs a short summary instead of the whole thing.

Compacting replaces the details of the old conversation with a summary. This story is for when that trade is fine with you; if it is not, raise the thresholds or switch the mod off.

How to read this diagram

Read the scenes left to right; they are numbered in the order things happen. The graph underneath follows one thing through the story: context size, which is what every message costs to read. Higher means more to read, so slower and more expensive.

  • You, using Claude Code in the cloud — You work with Claude in a cloud session, and you would rather not waste tokens.
  • The conversation gets hefty — Every message, file and reply is added to the context. It is now around 150k tokens.
  • You step away and forget — Lunch, a meeting, the weekend. The cache that made each message cheap expires.
  • It is compacted for you — After 20 quiet minutes idle-compact has Claude Code swap the history for a short summary.
  • You return to a small context — Your next message reads a summary, not 150k uncached tokens: faster, and far cheaper.
  • Rising line — the conversation growing as you work.
  • The drop — the compaction. From here the line is green: the story with idle-compact.
  • Dotted line — what would happen without it: your next message re-reads about 150k tokens, uncached.
  • Shaded band — the stretch of the story in which you are away.

The words used here:

  • Cloud session — Claude Code running on a remote machine that you reach from the web or your phone. Claude Code's own idle compaction is switched off there, which is why idle-compact exists.
  • Context window — everything Claude reads to answer you: the whole conversation so far. It is measured in tokens; a token is roughly three quarters of a word.
  • Cache — while you are actively working, Claude Code keeps the conversation cached, so each new message only pays for what is new. After a pause the cache expires (a "cache miss"), and the next message pays for the entire conversation again.
  • Compact — replace the conversation so far with a short summary of it and carry on from there. Details that are not in the summary are gone from Claude's view.
