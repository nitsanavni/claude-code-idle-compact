idle-compact · the story

Claude can compact its own context when a piece of work is done

Compaction can also happen while you are working. idle-compact gives Claude a tool that compacts the conversation right after its current reply. Use it when a piece of work is finished.

This path skips both the 20-minute wait and the size check: it compacts one second after the reply ends, whatever the size.

How to read this diagram

Read the scenes left to right; they are numbered in the order things happen. The graph underneath follows one thing through the story: context size, which is what every message has to carry. Higher means more to read, so slower and more expensive.

  • A long session — You and Claude work on a large task. The context grows.
  • A piece of work is finished — For example, the tests pass. Most of the history is no longer needed.
  • Claude calls the tool — You ask for a compaction, or Claude decides to compact. Claude calls compact_after_turn.
  • Compaction after the reply — It runs one second after the reply ends. There is no 20-minute wait and no size check.
  • The next task starts with a small context — The session continues. Each later message reads less.
  • Rising line — the conversation growing as you work.
  • The drop — the compaction. From here the line is green: the story with idle-compact.
  • Dotted line — what would happen without it: every later message reads the whole history.
  • Tinted box — an extra that is not part of the timeline: three tools for Claude.

The words used here:

  • Tool — an action an add-on makes available to Claude. You do not call it yourself; you ask Claude in plain words and it uses the tool.
  • Turn — one round of the conversation: your message, and everything Claude does until its reply is done.
  • Context — everything Claude reads to answer you: the whole conversation so far, measured in tokens (a token is roughly three quarters of a word).
  • Compact — replace the conversation so far with a short summary of it and carry on from there. Details that are not in the summary are gone from Claude's view.
