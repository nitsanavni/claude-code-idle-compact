Twenty quiet minutes, then a compact

When Claude finishes a reply, idle-compact starts a 20-minute countdown. Nobody sends a message, the countdown runs out, and the conversation is big enough, so it is compacted into a short summary before you come back.

How to read this diagram

Each row is a lane: the timeline of one actor (Claude, Countdown, Compaction), read left to right. The numbers along the top mark elapsed time; the faint vertical lines let you line moments up across lanes.

A marble (a round dot) is a moment, something that happens at one instant. Each marble carries a letter; this is what the letters stand for:

  • message sent — you ask, Claude starts
  • reply done — the countdown starts
  • time is up — big enough: over 120k tokens
  • compacted — now a short summary

A pill is a span, something that lasts. Its length is its duration:

  • Claude working
  • idle countdown · 20 min
  • Time break — the timeline skips ahead here (+10 min); time is not to scale across it, so a span that crosses it lasts longer than it looks.
  • Thin line — time passing with nothing happening. A gap in a lane means that actor is inactive.

The Detail buttons above the figure are five ready-made views, from Text (the diagram typed out in plain characters, the way its source is written: - a lane, ● a marble, bold = something that lasts, ≈ a time break) through Schematic (the same thing drawn, with no words) to Full. The Show switches under them turn single parts on and off, and the spacing adjusts to what is shown. The page address keeps the view, so you can link to it.

The words used here:

  • Compact — Claude Code replaces the conversation so far with a short summary of it, so the next message has far less to re-read.
  • Tokens — the units a conversation is measured in; a token is roughly three quarters of a word. 120k is 120,000 tokens.
