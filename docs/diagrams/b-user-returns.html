Coming back early cancels the timer

The user returns after nine minutes. The new turn.start cancels the pending timer, so nothing is compacted mid-thought. When that turn completes, a fresh 20-minute timer is armed.

1 column = 1 minute; the ≈ break skips ten quiet minutes. Every turn end re-arms from zero; there is never more than one timer.

How to read this diagram

Each row is a lane: the timeline of one actor (Claude, Timer, Compact), read left to right. The numbers along the top mark elapsed time; the faint vertical lines let you line moments up across lanes.

A marble is a moment, something that happens at one instant. The letter in it is its symbol in the ASCII source:

  • turn.start
  • turn.complete — arms the timer

A pill is a span, something that lasts. Its length is its duration:

  • turn
  • idle timer · 20 min
  • Cross — a cancellation: the span is cut off here, before it ran its course.
  • Arrowhead — the span is still running past the right edge.
  • Time break — the timeline skips ahead here (+10 min); time is not to scale across it, so a span that crosses it lasts longer than it looks.
  • Thin line — time passing with nothing happening. A gap in a lane means that actor is inactive.
